# Group 8 Capstone Project: Planets App

A responsive planets web app built for the Hajime cohort capstone. It shows 
one planet at a time, with a searchable planet card and a comparison table, 
in light and dark mode.

Built with HTML, CSS, and JavaScript. Planet data is fetched from a JSON API.

## How we work
- Never push directly to `main`.
- Each person works on their own branch, named after their task (see the 
  table above).
- When your work is ready, open a Pull Request.
- The person who opens a Pull Request must not merge it. Someone else 
  reviews and merges it.
- Pushes are merged twice daily, 5pm and 9pm.
