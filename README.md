
# 🪐 Group 8 — Planets App

**TS Academy | Frontend Development | Hajime Cohort**

A responsive planets web application developed as the Group 8 Capstone Project for the TS Academy Hajime Cohort.

Built with **HTML, CSS, and JavaScript**, the application allows users to search for planets, explore their characteristics, compare planetary facts, and switch between light and dark modes.

## ✨ Features

- **Planet Search:** Search for planets by name and view their information.
- **Planet Information Card:** Displays planetary facts and characteristics.
- **Planet Comparison Table:** Compares physical properties of planets in the solar system.
- **Light and Dark Modes:** Switch between themes for a personalised viewing experience.
- **Responsive Design:** Designed for desktop, tablet, and mobile devices.
- **Dynamic Planet Data:** Fetches planetary information from an external JSON API.
- **Loading and Error States:** Provides feedback while fetching data or handling unsuccessful searches.

## 🛠️ Technologies Used

- **HTML5** — Semantic page structure and content.
- **CSS3** — Styling, responsive layouts, and theme support.
- **JavaScript** — Search functionality, API integration, and theme switching.
- **JSON API** — Dynamic planetary information.
- **Git & GitHub** — Version control, collaboration, and pull request reviews.
- **Netlify** — Website deployment and hosting.

## 🚀 Running the Project Locally

You can access the project's source code through our [GitHub Repository](https://github.com/muni-standing/group-8-frontend-capstone-hajime-cohort).

Follow the steps below to run the Planets App on your computer.

### Prerequisites

- A web browser, such as Chrome, Edge, or Firefox.
- Git installed on your computer.
- Visual Studio Code (recommended).
- Live Server extension for VS Code (recommended).
- An internet connection for fetching data from the API.

### Step 1 — Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/muni-standing/group-8-frontend-capstone-hajime-cohort.git
```

### Step 2 — Navigate to the Project Directory

```bash
cd group-8-frontend-capstone-hajime-cohort
```

### Step 3 — Open the Project in VS Code

```bash
code .
```

Alternatively, open the project folder manually in VS Code.

### Step 4 — Launch the Application

1. Open `index.html` in VS Code.
2. Right-click inside the file.
3. Select **Open with Live Server**.
4. The application should open in your default web browser.

**Note:** No npm installation or build process is required because this project uses HTML, CSS, and vanilla JavaScript.

## 🔗 Planetary Data

The application retrieves planetary information from the following JSON API:

[Planet Data JSON API](https://anurella.github.io/json/planet.json)

The comparison table presents planetary facts based on the NASA reference data used for the project.

## 🤝 Development Workflow

Group 8 followed a collaborative GitHub workflow throughout the project.

- Team members worked on task-specific branches.
- Completed contributions were submitted through pull requests (PRs).
- Pull requests were reviewed before being merged into `main`.
- Direct pushes to `main` were restricted to protect the project.
- Team members collaborated on integration, troubleshooting, bug fixes, and code reviews.
- Final corrections and documentation updates were consolidated into the `final-integration-group-8` branch for review before submission.

The Planets App is deployed on Netlify and connected to our GitHub repository. Updates merged into the `main` branch trigger a new deployment.
